# 麻将算番 · 网页版

拍照算番，适配多种麻将标准和规则。

## 直接打开
双击 `index.html` 即可，不需要装环境、不需要服务器。

## 手机上用
```bash
node ../tools/serve.js 8000   # 起个本地静态服务
```
控制台会打印局域网地址，手机浏览器输入即可。

## 功能
- 拍照算番：本地图像处理，不联网、不调模型
- 番型规则说明：每个番型配图示
- 牌面悬浮抽屉：上拉查看已选牌面
- 花牌直接点选录入
- 局域网开房、记分
- 支持规则：国标麻将、日本立直、四川血流等

## 注意
网页版没有「我当主机」能力（内置房间服务器只在安卓/iOS App 里提供），
打开后该按钮会自动隐藏。局域网开房和记分网页版可用，房间数据存在各自浏览器。
